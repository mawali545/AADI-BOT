# DR Candle Tracker

The isolated `dr-candle-tracker` branch contains the DR Candle Tracker mobile package in `DR_CANDLE_TRACKER.zip`. This is separate from the AADI engine. GitHub Actions unpacks it, runs Python and userscript syntax checks plus six unit tests, then publishes a downloadable Termux ZIP artifact. No demo ticks or automatic trades are used.

See the package README for installation and Market-QX browser bridge setup.
